1. Ambulance Alarm System
A simple Arduino project to simulate an ambulance alarm using an RGB LED and a buzzer.

Requirements:
Arduino Board (e.g., Arduino Uno)
RGB LED: Simulates flashing red and blue lights
Buzzer: Simulates the ambulance siren sound
Jumper Wires
Breadboard

Setup:
Connect the RGB LED and buzzer to the specified pins.
Upload the Arduino code.
